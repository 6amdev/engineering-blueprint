# ui-design — หน้าตาและประสบการณ์ใช้งาน

> ขั้น 3 (ก่อน "go") และขั้น 5–6 (เทียบของจริง) · `design` ดูโครงสร้างระบบ ตัวนี้ดูสิ่งที่ผู้ใช้เห็นและทำ

## เมื่อไหร่ใช้
มีหน้าจอใหม่หรือเปลี่ยน flow · คนบอกว่าไม่สวย/ใช้ยาก · แก้ข้อความหรือสีเล็กน้อย = ข้ามได้ บอกเหตุผลบนการ์ด

## input
spec + flow · ใครใช้ ที่ไหน อุปกรณ์อะไร รีบแค่ไหน · แบรนด์/ตัวอย่างที่ชอบ · `docs/design-system.md` (ถ้ามี) · ภาพหน้าจอปัจจุบัน

## ขั้นตอน
1. **ตั้งโจทย์**: ผู้ใช้มาทำงานอะไรให้เสร็จ · งานที่ทำบ่อยสุด 1 อย่าง · ความรู้สึก 3 คำ · ชนิดหน้า: ทำงานให้เสร็จ (ชัด เร็ว สม่ำเสมอ) / ชวนเชื่อ (มีจุดยืน ภาพแรง) / อ่าน (สบายตา)
2. **วิจารณ์ของเดิม** (ถ้ามี) ไม่เกิน 6 ข้อ ชี้จุด: สิ่งสำคัญเด่นพอไหม · ก้าวไปงานหลักกี่ขั้น · อ่านสแกนง่ายไหม · ระยะและแนวสม่ำเสมอไหม · สีบอกความหมายไหม · ข้อความคนทั่วไปเข้าใจไหม
3. **ร่าง 2–3 แนวที่ต่างกันจริง** (ต่างที่โครงและวิธีทำงาน ไม่ใช่แค่สี) เป็น HTML นิ่ง + ภาพ ใช้ข้อมูลเหมือนจริงรวมชื่อยาว รายการว่าง รายการเต็ม · บอกเหมาะกับใคร แลกกับอะไร + คำแนะนำ 1 แนว
4. **คนเลือกจากภาพ** → บันทึกเป็นส่วนหนึ่งของ "go" · ยังไม่เลือก = ยังไม่เขียน
5. **กำหนด token** ใน `docs/design-system.md`: สีตามหน้าที่ (พื้น ตัวอักษร หลัก สำเร็จ เตือน ผิด) สว่าง+มืด · ขนาดตัวอักษร 4–6 ระดับ · ระยะเป็นขั้น · มุม เงา · component + ทุกสถานะ
6. **ทุกสถานะ**: ปกติ · hover/focus/กด · โหลด · ว่าง · ผิดพลาด · สำเร็จ · ไม่มีสิทธิ์ · ข้อมูลยาว · ออฟไลน์
7. **เขียนตาม token** ไม่ใส่ค่าสี/ระยะลอย ๆ
8. **เทียบจริงกับแบบ**: ภาพ 320 · 375 · desktop · สว่าง/มืด วางคู่ภาพที่เลือก → รายการที่ต่าง + แก้ · qa-engineer ให้คะแนน

## ให้คะแนน (qa-engineer · 0–2 ต่อข้อ · ผ่าน ≥ 12/16 และไม่มี 0)
| ข้อ | 2 = |
|---|---|
| งานหลักเด่น | คนใหม่รู้ใน 5 วินาทีว่าทำอะไรต่อ |
| ขั้นน้อย | งานหลักไม่เกินจำนวนขั้นใน spec |
| ลำดับสายตา | หัว/เนื้อ/รองต่างกันชัด มีจุดเน้นเดียว |
| สม่ำเสมอ | ระยะ แนว component มาจาก token |
| สีมีความหมาย | สีหลักใช้กับการกระทำ ไม่สื่อด้วยสีอย่างเดียว |
| ข้อความ | สั้น ภาษาผู้ใช้ บอกทางแก้เมื่อผิด |
| สถานะครบ | ทุกสถานะในข้อ 6 ออกแบบแล้ว |
| ใช้ได้ทุกคน | WCAG 2.2 AA · แตะ ≥ 44px · คีย์บอร์ด |

## หลีกเลี่ยง (ลายเซ็นของหน้าที่ AI สร้าง)
ไล่สีม่วง-น้ำเงินทุกหน้า · การ์ดซ้อนการ์ด · ไอคอนหรือ emoji ประดับทุกหัวข้อ · ทุกอย่างจัดกลางและหนักเท่ากัน · ตัวเทาจางบนพื้นสี · เงาและมุมมนเท่ากันหมด · ข้อความโฆษณาในหน้าทำงาน

## ตัวเสริม (ไม่บังคับ)

## output
