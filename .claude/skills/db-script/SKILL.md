# db-script — สคริปต์ DB ที่ตรวจและอนุมัติได้

> กฎเต็ม: `docs/db-scripts.md` · ด่าน DB-READ / DB-WRITE ใน `docs/gates.md`

## เมื่อไหร่ใช้
ต้องใช้ข้อมูลจาก DB จริง หรือต้องแก้/ย้ายข้อมูล · เขียนข้อมูล prod = R3

## input
คำถามหรือผลที่ต้องการ · ชื่อ DB เป้าหมาย · การ์ด · สิทธิ์ของบัญชีที่สคริปต์ใช้

## ขั้นตอน
1. **แผนสั้นก่อนเขียน**: ต้องการรู้/เปลี่ยนอะไร · ตารางใด · อ่านหรือเขียน (หนึ่งไฟล์ทำอย่างเดียว) · แถวที่คาด · ผลเสียถ้าผิด
2. **อ่าน**: บัญชี read-only · เฉพาะคอลัมน์ที่ใช้ · limit + timeout · ผลเป็นจำนวน/สถิติ · แยก "ไม่พบ" กับ "ตรวจไม่ครบ" ด้วย exit code
3. **เขียน**: dry-run เป็นค่าเริ่มต้น · apply ต้องใส่ flag · ยืนยันชื่อฐานข้อมูลเป้าหมายแบบตรงทุกตัวอักษร · allowlist ตาราง/คอลัมน์ · transaction หรือ batch · จำกัดจำนวนแถว
4. **backup + ทางถอย** พร้อมและทดสอบบน UAT ก่อน apply
5. **เทส**: สคริปต์อ่านเขียน 0 แถว · dry-run เขียน 0 แถว · ข้อมูลที่รู้คำตอบให้ผลถูก · ชื่อ DB ผิด/นอก allowlist ถูกปฏิเสธ
6. **ค่าลับ**: รับจาก environment ตอนรัน · ไม่พิมพ์ ไม่ commit · ไม่อ่าน `.env*`
7. **checklist มือ** ตาม `docs/db-scripts.md` + รันบน UAT · โปรเจกต์ที่มีคำสั่งตรวจอัตโนมัติใส่เพิ่ม (`กรอกต่อโปรเจกต์:`)
8. **ขออนุมัติ**: prod-reader คำนวณ sha256 → คำขอจาก `templates/db-read-approval-request.md` → โพสต์ (skill `post`) · เขียน = ใบขอ deploy + ด่าน DB-WRITE
9. **หลังอนุมัติ**: hash ตรงกับไฟล์ปัจจุบัน · แก้ไฟล์ = ขอใหม่ · อ่าน: prod-reader รัน · เขียน: Ops รัน · บันทึกผล + เวลา + hash บนการ์ด

## output
สคริปต์ + เทสใน `scripts/db/` · คำขอและผลรัน (ไม่มี PII) บนการ์ด

## agents
implementer (เขียน) · test-engineer (เทส) · security-engineer (injection · สิทธิ์ · PII) · prod-reader (เตรียม + รันอ่านหลังอนุมัติ)

## gates
GATE-VERIFY · GATE-SEC · DB-READ หรือ DB-WRITE · GATE-PRIVACY เมื่อมีข้อมูลส่วนบุคคล

## หยุดถาม owner เมื่อ
เขียน/ลบ/ย้ายข้อมูลจริง · อ่านข้อมูลส่วนบุคคล · เป้าหมายหรือ allowlist ไม่ชัด

## checklist done
- [ ] แผนสั้น · limit + timeout · ตรวจชื่อ DB · เขียน: dry-run + allowlist + backup + ทางถอย
- [ ] เทสผ่าน · checklist มือครบ · รันบน UAT แล้ว
- [ ] การอนุมัติอ่านข้อมูลจริงที่ผูกกับ hash ของสคริปต์ (ดู `docs/db-scripts.md`) บันทึกผู้อนุมัติ + วันที่ + hash
- [ ] ผลไม่มีค่าลับ/PII
