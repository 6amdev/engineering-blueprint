# เข้าสู่ระบบ

> สถานะ: v0.3.0 (2026-11-21)

::: warning ตัวอย่าง
หน้านี้เป็น **ตัวอย่าง** · กรอกต่อโปรเจกต์: วิธีเข้าสู่ระบบจริงของระบบคุณ (SSO / รหัสผ่าน / อื่น ๆ) และภาพหน้าจอจากระบบ UAT ที่ไม่มีข้อมูลจริง
:::

เข้าสู่ระบบด้วยบัญชีขององค์กร เพื่อดูห้องว่างและจองห้อง

## ก่อนเริ่ม
- มีบัญชีผู้ใช้ขององค์กรที่เปิดใช้งานแล้ว
- รู้ที่อยู่ของระบบ (ตัวอย่าง: `https://booking.example.com`)
- ถ้าองค์กรเปิดยืนยันตัวตน 2 ขั้น (MFA): เตรียมแอปยืนยันตัวตนในมือถือ

## ขั้นตอน
1. เปิด `https://booking.example.com` ในเบราว์เซอร์
2. กด **เข้าสู่ระบบด้วยบัญชีองค์กร**
3. ใส่บัญชีและรหัสผ่านในหน้าของผู้ให้บริการบัญชีองค์กร (ระบบจองไม่เห็นรหัสผ่านของคุณ)
4. ถ้ามีการถาม: ยืนยันตัวตนด้วยแอปในมือถือ
5. กลับมาที่หน้าแรกของระบบจอง

## ผลที่ควรเห็น
- มุมขวาบนแสดงชื่อของคุณ
- หน้าแรกแสดงปฏิทินและห้องที่ว่างวันนี้

## ปัญหาที่พบบ่อย
| อาการ | ทำอย่างไร |
|---|---|
| ขึ้นว่า "ไม่มีสิทธิ์ใช้งานระบบนี้" | บัญชียังไม่ได้รับสิทธิ์ · แจ้งทีมดูแลระบบ |
| กลับมาหน้าเข้าสู่ระบบซ้ำ ๆ | เปิดให้เบราว์เซอร์เก็บ cookie ของระบบ แล้วลองใหม่ · หรือลองหน้าต่างใหม่ |
| ไม่ได้รับคำขอยืนยันในมือถือ | ตรวจว่าเปิดเน็ตในมือถือ · เปิดแอปยืนยันตัวตนเอง แล้วกดรีเฟรช |
| ลืมรหัสผ่าน | ใช้ช่องทางรีเซ็ตรหัสผ่านขององค์กร (ระบบจองรีเซ็ตให้ไม่ได้) |
