## checklist
**ถูกต้อง**
- [ ] ตรงกับ spec ทุก FR / oracle · ไม่มีของนอก scope
- [ ] มีหลักฐานเทสที่ไม่ผ่านก่อนแก้ (RED) · เทสไม่ถูกแก้ให้ตรงโค้ด
- [ ] ไม่มีเทสที่เคยผ่านแล้วกลับมาไม่ผ่าน (แนบผล CI)
- [ ] เคส error / ขอบ / ซ้ำ / พร้อมกัน ถูกจัดการ
- [ ] ไม่มี logic ซ้ำที่ควร reuse · ไม่มีโค้ดตาย

**ความปลอดภัย (OWASP Top 10 · R1 checklist นี้ · R2 ASVS L1 · R3 ASVS L2)**

- [ ] ไม่มี secret/PII ในโค้ด log หรือ error
- [ ] dependency ใหม่ผ่าน GATE-DEPS (ถ้ามี)
